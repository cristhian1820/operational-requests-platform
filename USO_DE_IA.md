# Uso de IA

Se utilizó OpenAI Codex para inspección, implementación del frontend React/Module Federation, integración Keycloak, contratos Zod, pruebas, contenedores y documentación, además del trabajo previo de backend y eventos.

El candidato debe revisar reglas, accesibilidad, UX, dependencias npm, ownership de sesión, configuración productiva, transacciones y operación. Arquitectura, seguridad y aceptación visual siguen siendo su responsabilidad.

Las verificaciones efectivamente ejecutadas se reportan al cierre. No se considera probado un flujo solo porque compile o esté documentado.
