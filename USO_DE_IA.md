# Uso de IA

Se utilizó OpenAI Codex como asistente para inspeccionar el repositorio, proponer la estructura, crear configuración y código base, redactar migraciones/ADRs/contratos y ejecutar verificaciones técnicas.

La IA no sustituye la revisión del candidato. Deben revisarse manualmente las reglas del dominio, amenazas, permisos OAuth2, SQL y planes de ejecución, compatibilidad real de imágenes en la máquina destino, licencias, accesibilidad y decisiones productivas. El candidato sigue siendo responsable de arquitectura, seguridad, calidad, operación y de explicar cada decisión.

Las verificaciones realmente ejecutadas y sus resultados se informan al cierre de esta fase; este documento no afirma que Docker o integraciones externas hayan pasado antes de ejecutarlas.
