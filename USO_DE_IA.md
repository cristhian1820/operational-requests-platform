# Uso de IA

Se utilizó OpenAI Codex para inspección, implementación del publicador Outbox, configuración Kafka, consumidor idempotente, modelo analítico, pruebas, documentación y ejecución de validaciones.

El candidato debe revisar reglas, transacciones, SQL de locking, estrategia DLT, permisos, observabilidad, capacidad y configuración productiva. Arquitectura, seguridad y operación siguen siendo su responsabilidad.

Las verificaciones efectivamente ejecutadas se reportan al cierre. No se considera probado un flujo solo porque compile o esté documentado.
